# 本科生应该知道的教学知识（教学全过程指南）

> 数据来源：《河南大学本科生应该知道的教学知识》（官方 PDF，按在校全周期整理）

## 一、学籍注册与选课

- 学分制以选课为核心，通过**学分 + 绩点**衡量学习质量。
- 选课分阶段进行（预选/正选/补退选等），具体时间以教务系统通知为准；每学期应修学分一般在 **15-30 学分**区间。
- 新生入学需按时完成学籍注册、入学资格复查等手续。

## 二、考试与成绩

### 缓考
- 因事一般不允许缓考；因病或其他特殊原因确实不能参加考试者，须于**该门课程考试之前**办理缓考手续。
- 考试过程中突发疾病需补办缓考者，须有监考教师及辅导员出具书面证明。
- 无正当理由在考试开始后递交缓考申请无效；未申请或申请未批准而不参加考试者按缺考处理。
- 缓考课程考试安排在**下学期开学初**进行，缓考成绩按对应课程成绩构成综合评定。

### 补考
- 学生补考成绩如实记载：低于 60 分按实际成绩计；**高于 60 分（含）的一律以 60 分计**，成绩单备注「补考」。
- 对通过补考、重修获得的成绩，成绩单中予以标注。

### 绩点（重点 ⚠️）
绩点是评价学习质量、出国留学、交流学习、评优奖先的重要依据。课程绩点换算表：

| 分数段 | 绩点 | 等级 |
|---|---|---|
| 90 ≤ M ≤ 100 | 4.0 | A |
| 86 ≤ M < 90 | 3.7 | A- |
| 83 ≤ M < 86 | 3.3 | B+ |
| 80 ≤ M < 83 | 3.0 | B |
| 76 ≤ M < 80 | 2.7 | B- |
| 73 ≤ M < 76 | 2.3 | C+ |
| 70 ≤ M < 73 | 2.0 | C |
| 66 ≤ M < 70 | 1.7 | C- |
| 63 ≤ M < 66 | 1.3 | D+ |
| 60 ≤ M < 63 | 1.0 | D |
| 补考及格 | 1.0 | D |
| 不及格 | 0 | F |

平均学分绩点 = 各课程（学分 × 绩点）之和 ÷ 总学分。

## 三、学籍异动

- **休学**：因病或其他原因可申请休学，休学期间保留学籍。
- **退学**：符合规定情形（见教务管理规范）会被劝退或按退学处理，需谨慎对待。
- **重修**：课程不及格可重修，重修成绩如实记载（成绩单标注）；重修课程与已修课程上课时间冲突的可申请免听该门重修课程。

## 四、辅修与等级考试

- **辅修**：学有余力的学生可申请辅修其他专业（主修课程平均绩点一般需 ≥ 2.5，见教务规范），修满规定学分可获辅修证书/学位。
- **等级考试**：英语四六级（CET-4/6）、全国计算机等级考试（NCRE）、普通话水平测试、教师资格证等，大一即可参加（以当年报名通知为准）。

## 五、转专业与学业预警

- **转专业**：限报 1 个专业，各学院接收计划不超过本专业在校生人数的 30%，8 类情形不得申请（详见 major-transfer.md）。一般大一下学期申请。
- **学业预警**（每学期开展一次）：
  | 级别 | 触发条件 |
  |---|---|
  | 黄色预警 | 入学以来平均每学期所获学分低于 15 分 |
  | 橙色预警 | 除休学、保留学籍外，基本学制内达不到毕业条件、需延长学习年限 |
  | 红色预警 | 平均每学期所获学分低于 10 分 |
  - 被预警学生将接受预警谈话、建立预警档案，并获学业帮扶。

## 六、特殊培养计划

### 明德计划（基础学科拔尖实验班）
- 落实教育部「六卓越一拔尖」计划 2.0，在基础性学科开设，共 **10 个实验班**：经济学、汉语言文学、化学、世界历史、数据科学与大数据技术、物理学、地理科学、生物科学、数学与应用数学、哲学。
- 每年**春季学期**招生，学生自愿报名，资格审查后考核选拔；培养过程引入淘汰机制。

### 卓越计划（应用型/新工科新医科实验班）
- 共 **10 个项目**：临床医学（卓越医生）、法学（卓越法治人才）、生物科学（卓越农林人才）、网络与新媒体（卓越新闻传播人才）、化学工程与工艺（卓越工程师）、生物工程（卓越工程师）、软件工程（卓越工程师）、通信工程（卓越工程师）、土木工程（卓越工程师）、本硕一体化卓越中学教师培养计划。
- 每年**春季学期**招生，自愿报名 + 考核选拔，引入淘汰机制。

## 七、科研创新项目

- **大创项目**（大学生创新创业训练计划）：每年 **5 月**左右申报，分国家级、省级、校级立项。
- **开放性课题项目**：每年**秋季**申报，面向全校本科生开放。
- **学科竞赛**：自愿参加，竞赛获奖可在三评加分、保研加分。

## 八、免试研究生推荐（推免）⚠️ 重点

- 学校具有推免硕士资质，**大四第一学期开学初集中开展，每年 9 月 25 日前结束**。
- 条件要点：
  - 外语要求（非外语专业）：大学英语四级 **≥ 425 分**（其他小语种 ≥ 60 分），或**雅思 ≥ 5.5**、**托福 ≥ 65 分**；外语学院学生需通过专业四级。
  - 成绩要求：前三学年（五年制前四学年）课程学业考核总成绩排名在本年级相应专业**前 40%**，且在校期间**无不及格记录**。
  - 突出考查一贯学业表现 + 过程性评价 + 综合表现（竞赛获奖等可加分）。
- 流程：学院分配指标 → 以专业为单位资格审核和综合成绩评定 → 预推免名单公示 → 教务处汇总 → 学校审核 → 省招办审批、教育部备案 → 登录推免系统填志愿。

## 九、毕业与学位

- **毕业**：修满培养方案规定学分、达到毕业要求。
- **学位授予**：一般要求学位课程成绩合格、外语达标、无严重违纪（作弊记过以上处分通常不授学位，可通过考取研究生/获省部级以上奖励等途径补救，见教务规范）。
- **结业**：修满规定学分但未达毕业要求（如毕业论文未过），发结业证书，可在规定期限内申请换发毕业证。
- **肄业**：未修满规定学分即离校者，发肄业证书。
- **延长学习年限**：未能在基本学制内毕业者可申请延长学习年限。
- 毕业后如需补办毕业/学位证明书、查询档案，联系学校档案馆/教务处（学籍管理部门）。
