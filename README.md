# 河南大学新生攻略 · 校园百科

> SkillHub「宝藏母校 Skill 大赛」参赛作品 · 实用刚需赛道
>
> **河南大学新生入学全攻略 AI 助手：14 大刚需主题、官方一手数据、三校区精准答疑，无需联网即问即答。**

## 🎯 这是什么

一个专为河南大学新生和家长打造的 **AI 答疑助手（Skill）**。

新生入学前总有一堆问题：宿舍限电多少瓦？军训穿什么？转专业怎么申请？助学金怎么评？保研要什么条件？——这些信息散落在官网公告、群聊记录、学长学姐的口口相传里，难找还容易过时。

这个 Skill 把河南大学的入学信息整理成了 **结构化知识库**，覆盖 **14 大刚需主题**，并且：

- ✅ **官方一手数据**：素材来自学校官方文件，不是道听途说
- ✅ **三校区精准区分**：明伦（开封）/ 金明（开封）/ 龙子湖（郑州）信息严格分开
- ✅ **双版本标注**：遇到不同年度的数据差异（如助学金标准），同时标注并提示「以当年通知为准」
- ✅ **无需联网**：知识全部内置在本地 references 中，离线也能答
